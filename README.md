# privacy-policies

Static privacy policy pages for Nyvrane's apps, hosted via GitHub Pages.

## Structure

- `index.html` — hub page listing all apps
- `<app>/index.html` — one folder per app, served at `https://<user>.github.io/privacy-policies/<app>/`

## Adding a new app

1. Create a new folder named after the app (lowercase, hyphenated).
2. Copy an existing `<app>/index.html` as a template and edit the content.
3. Add a card for it in the root `index.html`.
4. Commit and push — GitHub Pages redeploys automatically.
